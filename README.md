# 🎮 Algo Rush – 2D Game Website

Algo Rush is a 2D educational game designed to improve students' programming, database, and number system skills.  
This website acts as the official platform where users can explore game features, view screenshots, download the game, and access their profiles.  
It also includes admin functionality, authentication, and modern UI components.

---

## 🚀 Project Overview

This project is part of a **2nd-year Skill Development group project**.  
The website is developed using **React + Vite** and connected with **Firebase Authentication & Database** to manage users and admin access.

The site includes:
- Game introduction & feature highlights  
- User login and profile pages  
- Admin dashboard with protected routes  
- Download option for the Algo Rush 2D game  
- Contact section  
- Fully responsive modern UI
